# Dados de capacidade de interação (G1)

Esta pasta pública recebe os dados revisados da Fase 4. Os caminhos abaixo são reservados para a coleta quando houver material autorizado e revisado.

| Caminho | Conteúdo permitido |
|---|---|
| `formularios/observacoes.csv` | Exportação das tarefas com código, primeiro destino, conclusão e contagem de passos |
| `formularios/questionario.csv` | Exportação anonimizada de SUS e aparência. Use totais agregados quando houver risco de identificação. |
| `gravacoes/` | Evidências derivadas e anonimizadas com autorização específica de publicação |
| `consolidacao.csv` | Valores por métrica e recorte, cobertura, nível e referência da evidência |

Use códigos sequenciais como `P01` e nomes de arquivo sem dados pessoais. Gravações originais, fichas preenchidas, a relação código–nome e termos assinados ficam no armazenamento privado. O [protocolo de participantes](../../../docs/fase-3/protocolo-participantes.md) define a guarda, os acessos e a revisão de publicação.
