# Qualidade de Software - 2026.2 - T02 - Dorothy Johnson

## Sobre o projeto

Avaliação da qualidade da Plataforma Territórios da Cidadania (SIT), sistema web público do Ministério do Desenvolvimento Agrário e Agricultura Familiar (MDA) que reúne dados, mapas e documentos dos territórios rurais. A avaliação segue o processo de avaliação de produto da SQuaRE (ISO/IEC 25040), considera as características Capacidade de interação, Flexibilidade e Eficiência de desempenho (ISO/IEC 25010:2023) e define as métricas com o método GQM. A gestão do projeto usa métricas PSM/CID.
